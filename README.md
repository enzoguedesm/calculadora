# Trabalhos e Exercícios de AED I - PUC Minas

## 📝 Descrição e Objetivo
Repositório dedicado aos códigos e projetos desenvolvidos para a disciplina de **Algoritmos e Estruturas de Dados I (AED I)** do 1º período do curso de Ciência da Computação da PUC Minas.

O objetivo é aplicar a lógica computacional, estruturação de dados estáticos, modularização com funções/procedimentos e técnicas de programação em linguagem estruturada para solucionar problemas práticos.

---

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** C
* **Ambiente / Compilador:** GCC / Code::Blocks / VS Code
* **Controle de Versão:** Git e GitHub
